# NFL Fourth-Down Decision Analytics

**Status: Work in progress**

A Python data science project exploring NFL fourth-down decisions using play-by-play data from the **2021–2025 seasons**.

## Project goal

Fourth-down decisions involve a tradeoff between attempting to gain a first down, punting, and kicking a field goal. This project examines how fourth-down conversion rates vary with game situation and aims to build a model that can help evaluate when attempting a conversion may be worthwhile.

## Questions being explored

- How does yards to go relate to fourth-down conversion probability?
- How does field position affect teams' decisions to go for it, punt, or attempt a field goal?
- How do score differential and time remaining influence fourth-down choices?
- How can estimated conversion probabilities inform decision-making?

## Data and approach

The analysis uses NFL play-by-play data for 2021–2025. The project focuses on fourth-down plays actually run, excluding timeouts and pre-snap penalties from conversion attempts. Variables under consideration include yards to go, field position, score differential, time remaining, and play outcome.

Current work includes exploratory analysis of conversion rates and decision patterns. Predictive modeling and decision evaluation are planned or in progress; results will be added as they are validated.
